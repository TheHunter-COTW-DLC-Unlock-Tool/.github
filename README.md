## 🧰 Requirements

Before using Linua Updater, make sure you have:

- A legitimate Steam installation of **theHunter: Call of the Wild**
- An active internet connection for DLC metadata retrieval
- **.NET 7 Runtime** installed
- Appropriate permissions for the game's installation directory

---

## 🚀 Installation & Setup

Getting started with Linua Updater is straightforward:

1. Download the latest release.
2. Extract the archive to a folder of your choice.
3. Launch the application.
4. Select your theHunter: Call of the Wild installation directory.
5. Follow the on-screen instructions.
6. Let the tool scan and verify the available game content.

Once everything is set up, you can use the application to manage supported DLC content and game configuration.

## 💡 Tips & Recommendations

- Always back up your game files before making configuration changes.
- Keep Linua Updater updated to maintain compatibility with newer game versions.
